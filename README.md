# Downshift support

Report bugs, suggest improvements, and follow progress on Downshift, the desktop Markdown editor from Gorewood Media.

- **Public discussion:** [Open an issue](https://github.com/gorewood/downshift-support/issues/new/choose) or browse [existing reports](https://github.com/gorewood/downshift-support/issues).
- **Private feedback:** Use **Send beta feedback** in Downshift or [the feedback form](https://feedback.gorewood.media/downshift). No GitHub account is needed for the private form.

GitHub issues and attachments here are public. Remove private document text, file paths, email addresses, and credentials before posting. Use the private form for sensitive reports, and avoid including secrets there too.

This repository contains support material. Downshift's source repository remains private. Private feedback is not automatically published here.

## Useful bug reports

Tell us what you were trying to do, what happened, and what you expected. Include the app version, operating system, and a small reproduction when possible. Screenshots help; check them for private content first. Never delete or replace your documents or recovery files to reproduce a problem.

## Following progress

We acknowledge reports, ask for clarification when needed, and label accepted issues as investigating, planned, or in progress. A closed issue should say whether it was fixed, duplicated, or not planned. Fix confirmations identify the released version when available; a code change alone does not mean a beta update has shipped.

Internal implementation tracking stays separate. Private reports may be represented here by a sanitized summary only with the reporter's permission. There is no promised response time during this early beta.
